# Simulation-and-Modeling
Assignments for Simulation and Modeling Course at ECE AUTH


Developed three MATLAB projects focused on modeling, simulation, and parameter estimation of dynamic systems:

1. Lyapunov-Based Adaptive Estimation:

      Implemented parallel and mixed Lyapunov adaptive laws for parameter estimation of first- and second-order dynamic systems.
      Simulated system responses with/without measurement noise and analyzed estimation errors.
      Explored the impact of tuning gains and adaptation parameters on convergence and accuracy.

2. Gradient Descent Adaptive Control:

      Designed a gradient descent-based adaptive algorithm for online parameter estimation.
      Evaluated system output tracking and parameter convergence under different input signals.
      Compared performance for various adaptation gains and reference signals.

3. System Identification via Least Squares and Recursive Estimation:

      Applied offline least-squares regression to estimate parameters of linear dynamic systems.
      Developed online recursive parameter estimation using adaptive filters and state-space representation.
      Tested multiple model orders and input combinations, and evaluated model selection using Akaike’s Information Criterion (AIC).
      Validated estimated models by simulating responses to test signals and analyzing output errors
